# よくあるエラー

| 症状 | 原因と確認 |
|---|---|
| `x.links is not iterable` | `links` またはパネルの `links` が `null`。`[]` にし、保存後の JSON と画面を再確認する |
| 作成成功だが取得が 403 | 保存先フォルダーの読み取り・更新権限がない。許可されたフォルダーに展開する |
| `Could not load plugin` | プラグイン CDN が通信制限されていないか確認する |
| ダッシュボードが読み込めない | 本体 JS の配信先、認証、保存定義、ブラウザのエラーを確認する |
| `No data` | パネルのクエリ・データソース・時間範囲・実際のクエリ応答を確認する |
| TLS 証明書エラー | 環境が提供する信頼済み CA と Chromium の信頼設定を確認する。検証を無効にしない |
| トークンが反映されない | 設定の保存と変数の存在を確認する。値は表示しない |
| 下書き保存が無効 | 同名の通常環境変数とネットワークシークレットの重複、値の検証エラーを確認する |
| 保存後に `check` が不一致 | Grafana の既定値補完や UI からの変更を `export` して差分確認する |

`plan` は読み取りのみ、`apply` は `--write` がない場合はプレビューです。実際の反映に失敗した場合は、成功と報告せずエラーの原因を解消してから再取得と画面チェックを行います。

ブラウザの周辺アプリ・解析通信は、サービスアカウント権限やネットワークポリシーで失敗する場合があります。対象パネルのクエリ、表示、読み込みエラーと分けて記録し、無関係な通信先や権限を一括で広げないでください。

検証結果は `.local/browser/<環境>/<ダッシュボード>/validation.json`、画像は同じ場所の `dashboard.png` です。トークンやブラウザの認証状態は出力しません。
