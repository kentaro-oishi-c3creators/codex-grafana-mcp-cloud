## パネルの中身

| パネル | 種類 | 入力と処理 |
|---|---|---|
| 月次推移：離職率・残業時間・エンゲージメント（グループ） | 時系列 | 月、年換算離職率、平均残業時間、エンゲージメントの12行。エンゲージメントは右軸 |
| 人員構成ピラミッド（年代×性別）と定年到達見込み | 横向き積み上げ棒グラフ | 年代帯6行と男女人数。現在は年代別構成の表示 |
| 会社別 主要人事KPI＋派生指標（離職リスク・生産性） | テーブル | 8社分の CSV をフィルターし、離職率・リスク・一人当たり売上・人件費率を計算 |
| 従業員数 | 数値 | 8社分の人数を同じ条件でフィルターし、`sum(hc)` を表示 |

会社別の入力には人数、採用人数、離職人数、勤続、年齢、女性管理職、残業、エンゲージメント、人件費、売上などの列があります。会社名や CSV の明細データはこの文書には転記していません。

## 派生指標の計算

| 指標 | クエリの計算式 |
|---|---|
| 離職率 | `(leave_v + leave_i) / hc * 100` |
| 離職リスクスコア | `ot_h * 1.2 + (5 - engage) * 15 + (40 - tenure) * 0.5` |
| 一人当たり売上（百万円） | `rev_m / hc` |
| 人件費 / 売上（%） | `cost_m / rev_m * 100` |

リスクスコアはデモ用の計算式です。学習済みの予測モデルや離職確率を示す実装ではありません。テーブルではスコア50から黄色、65から赤のしきい値を設定しています。

## 絞り込み

| 変数 | 表示名 | 選択肢 |
|---|---|---|
| `ctype` | 会社区分 | 親会社、子会社 |
| `segment` | 事業セグメント | 鉄道、バス、不動産、流通、ホテル |
| `region` | 地域 | 近畿、中国、九州 |

全て複数選択と All に対応する変数です。会社別テーブルと従業員数のクエリに、次の条件が保存されています。

```text
ctype IN (${ctype:singlequote}) && segment IN (${segment:singlequote}) && region IN (${region:singlequote})
```

月次推移と年代別構成のクエリにはこの条件がありません。現在の定義では、変数を変更してもこの2パネルは同じサンプル入力を使用します。All や複数選択が画面上で期待通り動くかは、別途ブラウザで検証する対象です。

## 今後確認したい点

1. 月次 CSV は2025-10-01〜2026-09-01ですが、保存時間範囲は `now-6h`〜`now`。月次グラフの時間範囲と入力日付が一致していません。今回の調査では表示変更・ブラウザ確認は行っていません。
2. 「定年到達見込み」というタイトルに対し、現在の入力は年代帯と男女人数だけです。定年年齢、到達年、予測人数などの専用クエリは見当たりません。
3. 会社フィルターが月次・年代別の2パネルには適用されません。全パネルを連動させたい場合はデータ構造とクエリを追加設計します。
4. 現在の Git 管理スクリプトは GridLayout 用です。このデモの AutoGridLayout を反映対象へ登録する際は、先に検証ツールの対応を追加します。

現時点ではダッシュボードの保存定義を調査しただけで、JSON を Git 管理対象に取り込んだり、自動反映する設定を追加したりはしていません。
